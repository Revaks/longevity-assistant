# Ассистент долголетия

Десктоп-приложение на Python/Tkinter: умный ассистент + календарь рекомендаций по продлению жизни.

Советы собраны из книги Алексея Москалева «120 лет жизни — только начало. Как победить старение?» и дополнены диетой MIND.

## Возможности

- **📅 Календарь** — недельная сетка с расписанием (сон, питание, тренировки, добавки, процедуры) и личными заметками на каждый день.
- **🥗 Питание** — правила диеты MIND (10 полезных и 5 ограничиваемых групп) и недельное меню. Меню можно сгенерировать локальной нейросетью Ollama.
- **📚 База знаний** — 70 советов по 4 категориям: образ жизни, питание, добавки, процедуры, с поиском и указанием источника (глава книги).
- **🤖 Умный ассистент** — чат на русском. Работает двумя способами:
  - поиск по базе знаний (без сети);
  - ответы локальной моделью Ollama с контекстом из книги (если запущена Ollama).

## Запуск

```bash
python3 app.py
```

Требуется Python 3.10+ с Tkinter (на Arch: `sudo pacman -S tk`).

Для генерации меню и ответов нейросетью нужна запущенная [Ollama](https://ollama.com) с любой моделью, например:

```bash
ollama run qwen2.5:7b
```

Если Ollama недоступна, ассистент и меню работают в режиме базы знаний.

## Файлы

- `app.py` — графический интерфейс (Tkinter)
- `knowledge_base.py` — советы из книги, расписание, правила и меню диеты MIND
- `notes.json` — ваши заметки календаря (создаётся автоматически)

## Дисклеймер

Информация носит научно-популярный характер и не заменяет консультацию врача. Лекарства и добавки — только по назначению специалиста.
