# Ассистент долголетия — Android

Нативная Android-версия десктопного приложения «Ассистент долголетия»
(Python/Tkinter). Ядро переписано на Kotlin: модели данных, проверка
целостности JSON, русский стеммер, поиск BM25F, SQLite-хранилище и
офлайн-ответы ассистента — всё работает локально, без сети.

## Возможности

- **Календарь** — неделя с выбором дня, план из расписания с цветами категорий,
  индикатор «есть заметки», подробный вид выбранного дня.
- **Активность** — отметки выполнения пунктов расписания на день, прогресс дня,
  сводка по неделе.
- **Заметки** — дневник с несколькими записями на день: добавление не заменяет
  старые, записи редактируются и удаляются по отдельности.
- **Питание** — недельное меню по диете MIND и правила (полезные группы +
  что ограничить).
- **База знаний** — вкладки «Советы» (поиск BM25 + фильтр по категории) и
  «Книги» (полные тексты трёх книг Москалева, поиск по отрывкам BM25);
  детали открываются отдельным экраном с подсветкой слов запроса.
- **Ассистент** — чат на русском: расписание дня/недели, ответы по советам и
  отрывкам книг (BM25, без сети), быстрые вопросы.

## Чем Android-версия отличается от десктопа

| Фича | Десктоп (Python) | Android (Kotlin) |
|---|---|---|
| Расписание, дневник, отметки | ✔ | ✔ |
| База знаний: советы + книги | ✔ | ✔ |
| Поиск BM25 по советам и книгам | ✔ | ✔ |
| Ассистент (офлайн, BM25) | ✔ | ✔ |
| Ответы и генерация меню через Ollama | опционально | не переносится |
| «Смысловой» поиск (вектора Ollama) | опционально | не переносится |

Ollama не переносится намеренно: это локальный сервер нейросети, который на
телефоне не запускается. При необходимости можно добавить подключение к
удалённому серверу Ollama — интерфейс для этого в коде не заложен.

Данные приложения (советы, расписание, синонимы, MIND, книги) лежат в
`app/src/main/assets/longevity/*.json` и не перекомпилируются — это те же
файлы, что и в `longevity/data/` у Python-версии.

## Сборка

```bash
cd android
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Требования: JDK 17+, Android SDK (platform 35). В Android Studio откройте
каталог `android/` как проект и запустите приложение на эмуляторе или
устройстве.

Минимальная версия Android: 8.0 (API 26).

## Тесты ядра (JVM)

Ядро не зависит от Android и покрыто обычными JVM-тестами, включая прогон на
настоящих данных приложения (82 совета, 848 отрывков книг):

```bash
cd android
./gradlew testDebugUnitTest
```

## Структура

```
android/
  app/src/main/java/com/revaks/longevity/
    core/          ядро: модели, стеммер (Text), загрузка (ContentLoader),
                   расписание (Schedule), BM25F (Search), ассистент
    data/          SQLite-хранилище (Storage): дневник, отметки, настройки
    ui/            MainActivity, DetailActivity и шесть вкладок
    LongevityApp.kt  загрузка данных из assets в фоне
  app/src/main/assets/longevity/   JSON-данные приложения
  app/src/test/    JVM-тесты ядра (JUnit)
```

Соответствие Python-модулям десктопа отмечено в комментариях к каждому файлу:
`longevity/text.py -> core/Text.kt`, `longevity/search.py -> core/Search.kt`,
`longevity/content.py -> core/ContentLoader.kt`, `longevity/storage.py ->
data/Storage.kt`, `longevity/schedule.py -> core/Schedule.kt`,
`ui/assistant_page.py -> core/AssistantEngine.kt` и т. д.

## Дисклеймер

Информация носит научно-популярный характер, собрана из книг А. А. Москалева и
не заменяет консультацию врача. Лекарства и добавки — только по назначению
специалиста.
